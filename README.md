# Minimum Wages and Employment — Replication and Extension
## Card & Krueger (1994), *AER* 84(4), 772–793

Individual project (ECO6067-style, AI-assisted empirical replication) that
replicates Tables 2–4 and Figure 1 of Card & Krueger (1994) using the public
Princeton survey data, and adds an independent extension on heterogeneity and
inference credibility.

## 3. Data and variables

- **Source.** The public replication data of Card & Krueger (1994) distributed
  by Princeton University (the course package `public.csv`, 410 restaurants).
  It is the standard "public.dat" survey file: 331 New Jersey and 79 eastern
  Pennsylvania Burger King / KFC / Roy Rogers / Wendy's restaurants, surveyed
  in February–March 1992 (wave 1) and November–December 1992 (wave 2).
- **Key definitions** (all verified against the paper):
  - `STATE` = 1 New Jersey (treated), 0 Pennsylvania (control).
  - FTE employment = `EMPFT + 0.5*EMPPT + NMGRS` (full-time + half of
    part-time + managers), reproducing the paper's wave-1 means 23.33 (PA) /
    20.44 (NJ).
  - Wave-2 employment: the 6 permanently closed stores (`STATUS2==3`) are set
    to 0; the 2 temporarily closed + 2 under renovation (`STATUS2` in {2,4,5})
    and the 1 refusal (`STATUS2==0`) are treated as missing in the baseline;
    an alternate series (`FTE2_zerotemp`) sets the four temporary stores to 0.
  - `GAP` = proportional starting-wage increase needed to reach $5.05
    (= 0 for PA and for NJ stores with wave-1 wage ≥ 5.05).
  - Wage classes: `$4.25`, `$4.26–$4.99`, `≥ $5.00` (wave-1 starting wage).
  - Chain dummies for Burger King / KFC / Roy Rogers (Wendy's = base);
    company-owned dummy; region dummies for NJ (North/Central/South) and PA
    (PA1/PA2).
- A data dictionary is in the appendix of `report/empirical_report.md`.

## 4. What the pipeline reproduces

| Deliverable | Result vs. paper |
|---|---|
| Table 2 (means, SEs, t-stats) | matches essentially row-by-row |
| Table 3 (employment before/after, DID) | rows 1–5 match; balanced-sample DID = 2.75 (1.34), temp-closed DID = 2.51 (1.35) — exact |
| Table 4 (reduced-form DID regressions) | cols (i)–(iv) exact: NJ 2.33 (1.19), GAP 15.65 (6.08); col (v) 11.98 (7.42) vs 11.91 (7.39); N = 357 exact |
| Figure 1 (wage distributions) | reproduced (wave-2 NJ mass at $5.05) |
| Table 5 subset (specification tests) | level models match; WLS prop NJ 0.13 (0.05) exact |

Documented differences are discussed in the report: the public data contains
6 fewer NJ stores with wave-1 wages than the authors' working data (affects
the midrange wage cell: 140 vs 146), so a few secondary cells differ slightly.
None changes the paper's qualitative conclusions.

## 5. Independent extension

"Who bore the adjustment, and how credible is the inference?" — (a) DID by
ownership (company-owned vs franchise) and chain; (b) within-PA placebo DID
(PA1 vs PA2); (c) randomization inference (10,000 permutations) vs conventional
t-inference. See `code/06_extension.py` and Section 6 of the report.

## 6. GitHub submission

The local repository already contains a complete, meaningful commit history
(data → cleaning → replication tables/figure → extension → validation →
report → docs). To publish it to GitHub:

```bash
# 1. create an empty repository on github.com (public or private; no README, no license)
# 2. connect and push the existing history
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

If you prefer not to publish `public.csv`, remove it from the repository before
pushing (`git rm --cached data/input/public.csv`) — the README documents how to
obtain it independently (it is the public Princeton replication file), and the
pipeline requires it only at `data/input/public.csv`.
