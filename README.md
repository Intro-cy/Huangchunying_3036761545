# Huangchunying_3036761545 — Minimum Wages and Employment
## Replication and Extension of Card & Krueger (1994), *AER* 84(4), 772–793

Individual project — AI-assisted empirical paper replication and extension.
This repository replicates **Tables 2–4 and Figure 1** of Card & Krueger (1994)
using the public Princeton survey data, validates the replication with a
subset of Table 5, and adds an independent extension on **heterogeneity** and
**inference credibility**. It is structured so that an AI agent (or any user)
can reproduce every table and figure by running a single script.

## 2. Reproduce everything

Requirements: Python ≥ 3.10, `pandas`, `numpy`, `statsmodels`, `matplotlib`, `scipy`.

```bash
pip install pandas numpy statsmodels matplotlib scipy
python3 code/run_all.py
```

That is the **only** command needed. It reads `data/raw/public.csv`, rebuilds
`data/processed/ck94_clean.csv`, and writes every table in `outputs/tables/`
and every figure in `outputs/figures/`. No manual data or code edits are
required between steps. Equivalent runner: `bash skills/scripts/regenerate.sh`.

## 3. The replication process (what the code does, step by step)

1. **Clean and construct variables** (`01_clean_data.py`, shared definitions
   in `ck94_utils.py`, all verified against the paper):
   - FTE employment = `EMPFT + 0.5*EMPPT + NMGRS` (reproduces the paper's
     wave-1 means exactly: PA 23.33, NJ 20.44).
   - Wave-2 employment: 6 permanently closed stores → 0; 2 temporarily closed
     + 2 under renovation + 1 refusal → missing (baseline).
   - `GAP = (5.05 − W1)/W1` for NJ stores with W1 < 5.05, else 0.
2. **Table 2 — Means of key variables** (`02_table2.py`): means, SEs and
   t-stats for both states, both waves; matches the paper row-by-row.
3. **Table 3 — Average employment before/after** (`03_table3.py`): five-row
   DID table; balanced-sample DID = **2.75 (SE 1.34)** — exact; temp-closed
   DID = **2.51 (1.35)** — exact.
4. **Table 4 — Reduced-form regressions** (`04_table4.py`): ΔFTE on the NJ
   dummy or GAP with chain/ownership (and region) controls, **N = 357**
   (exactly as in the paper); columns (i)–(iv) replicate to the digit.
5. **Figure 1 — Starting-wage distributions** (`05_figure1.py`): two-panel
   distribution in 10-cent bins from $4.25 to $5.55; wave-2 NJ massed at
   $5.05 (89.6%).
6. **Extension** (`06_extension.py`): ownership/chain heterogeneity DID,
   within-PA placebo, randomization inference (B = 10,000).
7. **Validation** (`07_spec_tests.py`): subset of the paper's Table 5
   specification tests (part-time weights, manager exclusion, shore-store
   exclusion, WLS, PA-only placebo).

## 5. Independent extension

**Economic question:** "Who bore the adjustment, and how credible is the
inference?" Three pieces of evidence:

1. **Heterogeneity** — group-specific DID by ownership and chain. The effect
   is broad-based (company-owned 2.04, franchise 3.13; chains 2.5–4.4); KFC is
   the only negative point estimate (−1.59), not statistically significant.
2. **Within-PA placebo** — untreated stores show no spurious
   wage–employment relationship (placebo DID −2.90 (2.43); Table-5 row-12
   style: −3.82 (20.10)).
3. **Randomization inference** (B = 10,000) — the headline DID survives an
   exact finite-sample test: permutation p = **0.018** (conventional t p =
   0.044), strengthening the paper's borderline t = 2.05.

## 6. Reusable skill

`skills/SKILL.md` packages the whole workflow as a reusable skill: it lists
inputs, steps, outputs, and a verification checklist (headline numbers that
must match the paper), and ships `skills/scripts/regenerate.sh` plus a data
dictionary in `skills/references/`. It regenerates the main tables and
figures with one command.

## 7. AI-use disclosure

`AI_USE_DISCLOSURE.md` documents where and how AI was used (paper reading,
code drafting, diagnostics, report drafting, workflow setup), how AI outputs
were checked (cross-verification against the paper, end-to-end reruns,
figure inspection, independent recomputation), and six important AI errors or
suggestions that were corrected or rejected (Table-4 sample rule, % full-time
definition, Table-5 model split, rejected extension designs, etc.).

## 8. Data availability

`data/raw/public.csv` is the **public** Card–Krueger replication data
distributed by Princeton University (course package 01). It is not restricted:
it can be re-downloaded from Princeton DSS or the course data page. If you
prefer not to publish it, run `git rm --cached data/raw/public.csv` before
pushing; the pipeline only requires it at that path.
